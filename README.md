# operating-system-security-and-networks

# Lab 3: Process Lifecycles and OS Interaction

# Overview

This lab demonstrates how C programs interact with the Linux Operating System and how processes are managed.

# Tasks

Task 1: Long-running process using `sleep()` and process monitoring with `ps`.
Task 2: Process identification using `getpid()` and `getppid()`.
Task 3: Exit codes using `return 0`, `return 1`, and `echo $?`.
Task 4: Standard input/output using `scanf()` and `printf()`.
Task 5: Conditional execution and process termination.
